# Contributing to Memeloop GEO

Thanks for helping improve Memeloop GEO. Please open an issue or discuss a
substantial design change before investing in a large pull request. Keep pull
requests focused, include tests for changed behaviour, and ensure the relevant
format, type, lint, and test checks pass locally.

Do not add credentials, customer data, session material, or production exports
to the repository. Tests and examples must use synthetic, scoped data.

## Licensing

The community codebase is AGPL-3.0-only and is also offered under commercial
terms. To preserve the project's ability to offer the commercial license, all
external contributors must sign the project's contributor license agreement
(CLA) before a contribution can be accepted. By submitting a pull request, you
confirm that you are authorized to submit the work and that it does not include
third-party material with incompatible licensing.
