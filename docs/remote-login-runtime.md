# 远程登录组件替换

状态：客户端、授权网关和 runner 转发已实现，端到端实机验收未完成。替换通用远程桌面交互，不重写账号、身份核验、加密会话和发布/测量流程。

当前接入使用 noVNC 1.7.0（MPL-2.0），生产构建保留上游许可和作者说明；客户端仅在打开远程登录时加载。客户账号与运营账号池共用组件，通过同源 `desktop-authorization` POST 取得短期一次性 WebSocket 子协议授权，再连接服务端确定的会话地址。授权绑定 Cookie 会话、租户、运营商与 Origin，不把 runner 地址或凭据交给客户端。断线重新授权，不新建浏览器会话。

网关检查权限及到期状态，runner 在完成、取消、过期时终止远程连接并关闭输入后才保存登录态或销毁显示。网络连接、转发和关闭使用有界超时，避免慢连接无限拖延回收。授权及交互会话仍依赖运行中的实例；尚未提供跨副本恢复，不可宣称重启后可继续同一未完成的登录窗口。保存后的账号凭据继续由既有加密持久化链路负责。

开发与生产前端均需要支持 ES2022；noVNC 的能力探测使用顶层 await。Vite 的生产 target 与开发依赖预构建 target 必须同步，不能只验证生产构建。真实 Linux 显示、中文输入、剪贴板、跨 ingress WebSocket 与真实账号验收仍按下文执行。

最新测试用第二个 Chromium 加载未修改的 noVNC，通过真实指针点击取得远端输入框焦点，发送字母、退格和 `中文😀` 剪贴板，逐字检查结果；独立 Linux 测试实例及 `cd0431a` 桌面 CI `37535324304` 均通过。测试也验证实际帧缓冲中的合成颜色区域、强制 PNG 截图和完成后断开，不把 DOM 字符串、握手或有效但空白的图片当作远程显示证明。身份仅检查 DOM/Cookie；此前 headed Chromium 截图异常不再被测试混同为身份失效。

中文字体不提供输入法。已验证的基线镜像未装 IBus，noVNC 的 canvas 键盘通路也没有证明支持本机 IME 组合输入。独立 IBus/libpinyin 实验的进程生命周期测试通过，但首次拼音组合仍丢字；该实验不能默认启用或作为中文输入验收。下一步评估成熟集成桌面的输入法支持及候选选择，不自制文字注入接口。Unicode 剪贴板依赖双方协商扩展能力，旧协议会损失非 Latin-1 字符；上述基线已实测精确粘贴，不能据此推断拼音组合也通过。

## 组件与运行环境

拟采用 noVNC 客户端、websockify WebSocket/RFB 转发和 TigerVNC/Xvnc 虚拟显示，运行有头 Playwright Chromium。接入前固定版本、核验维护状态及许可证分发义务；不能把依赖选型写成已完成安装。noVNC 本身不是浏览器服务，不能显示现有共享 headless Chromium。

交互登录与自动执行分开：交互登录使用独立浏览器进程和独立显示器，生产优先每会话独立容器或 pod；后台自动测量/发布仍复用现有 headless 执行链路。远程桌面必须操作后续身份核验、`storageState` 保存所使用的同一浏览器上下文，不复制到另一套不受管理的浏览器。

Windows 原生应用和数据库可保持运行，但此登录 runtime 需要 Linux 容器、WSL2/虚拟机或远程 Linux runner。不能仅安装 npm 客户端就宣称 Windows 本地远程桌面可用，也不能共享宿主主桌面。

## 接缝与实施顺序

1. `packages/browser-runner` 增加独立交互会话 runtime，继续应用原账号代理、身份识别、完成/关闭和会话保存。先以隔离 Linux 环境验证真实显示、登录及浏览器上下文一致性。
2. Rust 账号 API 增加同源 WebSocket 连接入口和短期会话绑定授权；校验登录、Origin、租户/运营商及会话归属。目标由服务端确定，不接受客户端 VNC 地址。runner 密钥、代理秘密及 Cookie 不下发客户端。
3. React 两种账号入口共用 noVNC 包装组件；替换截图轮询、坐标表单、按键枚举及自制点击映射。完成、取消、失效、撤权立即断开远程输入并回收资源。
4. 删除旧截图/action 接口及客户端，不保留双轨或自制回退；未部署成熟远程桌面 runtime 时明确不可用。正常后台无头发布/测量不受影响，不能为交互登录缺失而新增自制输入协议。

RFB 绕过现有逐动作登录控制守卫，必须重新验证会话输入生命周期、完成后断开及服务端隔离。前端按钮变灰不等于服务端撤权；页面事件守卫不能冒充无竞态的隔离机制。采用非 root、隔离文件系统及受限网络，不开放浏览器调试入口或宿主文件。

## 使用体验

- 普通文本正常显示，不额外掩码；凭据字段沿用被登录平台自己的行为。
- 使用成熟输入法、剪贴板和远程桌面能力；不新增自制文本注入通道。
- 安装并验证中文字体与远端输入法。必须实际测试中文组合输入、选字、退格和 Unicode/emoji 粘贴；noVNC 名称不能作为 IME 支持证据。
- 客户端缩放与服务端分辨率协商分开验收。断线重新授权后恢复同一未过期会话，而非悄悄创建空浏览器。
- 不增加账号用途声明、逐篇确认或人工审批。

## 交付验证

### CI 镜像交付

独立桌面 workflow 在容器内合成验收成功后导出同一个已测镜像，不在开发机重复构建。产物 `interactive-desktop-image-<commit>` 包含 `image.tar.zst`、`image-inspect.json`、`source-commit.txt` 和 `SHA256SUMS`，保留七天；镜像标签绑定完整提交。测试失败时仅保存合成诊断，不产生新的已验证镜像。

下载前核对 Actions 的仓库、分支、提交和成功状态；解压 artifact 后执行 `sha256sum -c SHA256SUMS`，再使用 `zstd -dc image.tar.zst | docker load` 导入。该镜像为 CI Linux 架构，不是 Windows 原生程序；需要兼容的 Linux Docker/containerd 执行环境。k3s 部署应通过受控镜像仓库或管理员维护的 containerd 导入流程，不为导入镜像给测试 Pod 增加宿主挂载或特权权限。镜像不包含登录态和环境密钥；运行凭据另由私有 Secret 注入。已有会话所在的服务切换须保留加密密钥和持久数据库，不能启动第二个执行器争抢同一批任务。

该交付步骤的实际产物与运行验收状态见工作日志；workflow 配置存在不代表镜像已构建或部署。

必须分别验证 Linux 无物理显示环境、生产 ingress WebSocket 和 Windows 客户端：

- 中文输入、剪贴板、滚动、触屏、窄屏、分辨率与焦点；
- 断线恢复，取消/过期/失权清理，身份保存后既有连接不可继续输入；
- 两租户并行隔离，跨站连接和过期凭据拒绝，客户端不能指定任意远程目标；
- 登录与后台执行出口一致，指定代理失败不直连；
- 实际登录→身份核验→加密保存→进程重启→模型发现→提问→答案与引用证据。

自动夹具和真实平台验收分别记录；真实身份、登录截图、凭据和运行地址不进入公开仓库。若本地 IME 等必需体验无法通过，再评估完整 KasmVNC 客户端/服务端方案，而非继续增加自制遥控功能。

## 输入法替代方案实验

现有拼音实验失败后，优先隔离验证 [KasmVNC](https://github.com/kasmtech/KasmVNC) 固定版本及其官方客户端的输入法模式。上游 [中文输入讨论](https://github.com/kasmtech/KasmVNC/issues/97) 和 [IME 文档](https://kasmweb.com/docs/latest/how_to/ime.html) 是选型依据，不是本产品实测结论。

- KasmVNC 仓库声明 GPL-2.0；所评估发行包声明 GPL-2+ 并附带其他组件说明，分发须按实际产物保留许可。它与传统 RFB/noVNC 不兼容，必须配对更换服务端与客户端，不能只换服务器二进制。
- 保留同一个 Playwright 浏览器上下文及显示器；授权保存登录态的上下文必须就是用户遥控的上下文。
- 完整客户端页面与 WebSocket 都走会话作用域下的同源入口，不能沿用只有 WebSocket 受保护的接线就直接暴露后端。
- 优先评估发行包。完整桌面镜像及其附加组件的许可需独立确认，不假设软件包许可证覆盖整张镜像。
- 备选 [Selkies](https://github.com/selkies-project/selkies) 核心为 MPL-2.0，另有组件许可，接入涉及更大的客户端/显示栈替换。选择包含已确认输入法修复的固定版本，不根据最新标签推断修复已在发布包中。

实验只使用合成页面，分别验证首字、连续短语、候选选择、退格、粘贴、断线恢复和完成后撤销。自动生成 composition 事件不能代替 Windows 原生输入法与候选窗口的实际操作验收。实验通过前不替换已有真实服务，也不把上游能力标成产品已可用。

首轮隔离试验已验证 v1.5.0 发行包摘要、官方客户端真实画面、指针以及同一 Playwright 上下文中的 ASCII/退格。受限容器的包配置阶段失败，仅解包后的服务端直接运行成功，不能算镜像安装或部署验收。中文、候选选择、Unicode 粘贴、网关鉴权及重连/撤销仍待验证；实验资源已回收，真实服务未切换。
