# 外部 AI 会话与证据保留

本契约细化账号接入与真实测量的资源生命周期，不改变测量成功标准。

## 用户行为

使用已有账号执行测量不应长期占用用户的外部会话列表。每个任务可能创建测量会话与提取会话，两者都由系统管理。日常任务无额外审批或清理表单。

系统先保存原始回答、引用、观测时间、来源与解析所需的有界原始证据，再进行解析。解析失败只改变解释状态，不意味着供应方没有回答。重新解释优先读取已保存的证据，不重新发送测量问题。不得把解释失败当成未执行而自动重复创建外部会话。

远端会话默认在本地证据持久化确认且不再被任务使用后删除；仅当删除能力不可用而归档能力可用时归档。删除失败不重跑原任务，不清空原始证据；账号失效后等待重连恢复清理。尚未保存完整结果的会话保留为待恢复，不先删后补。

## 归属与状态

使用独立资源记录关联 operator、tenant、project、账号、execution/attempt、用途（测量或提取）与外部 conversation ID。ID 必须来自本次新会话请求的关联响应或已验证页面，不按标题、时间相近、当前账号或空白页面推断归属。

资源状态至少区分：已识别、证据待保存、证据已持久化、待清理、已删除、已归档、清理结果未知、需重新登录。引用本地证据版本/摘要和存储回执；临时缓冲、浏览器页面关闭、模型解析成功均不算持久化确认。

清理任务仅可作用于精确归属且已经保存证据的会话。删除前再次检查账号身份、会话 ID 与活动任务引用。结果未知时先只读核对远端是否仍存在，不重发测量，也不泛化为清空账号全部历史。

解析得到的 verified/unknown 与资源清理状态相互独立；保留原失败记录，不能通过修改历史状态伪装成功。

## 历史恢复

优先由既有执行证据中的外部 ID 建立可证明的映射；对尚未采集的完整输出先恢复并入库。未保留外部 ID 的历史任务不能仅凭名称批量删除。无法归属的会话保持原状，记录恢复缺口，不宣称历史已清空。

## 实现与部署接线

迁移 `0041_observation_captures.sql` 保存不可变来源、原始提取及候选快照。来源为 ordinal 0，原始提取和候选共享递增序号并引用来源；同一尝试/执行会话的重放只能复用原内容，不能覆盖证据。存储回执不等于测量成功或删除许可。完成证据独立于答案语义：须同时保留成功终止的传输、精确会话身份、每条消息身份及最后一次明确的助手完成状态；未知状态仍可保存原文，但不授予删除能力。

API 使用 `GEO_BROWSER_RUNNER_CALLBACK_TOKEN` 配置服务身份，并通过已有 `GEO_CHANNEL_SECRET_KEY` 密封作用域/账号/尝试/会话绑定票据。仅持久数据库装配启用回调；配置缺失不会伪造回执。执行器的 `GEO_BROWSER_RUNNER_CALLBACK_ORIGIN` 指向部署选定的 API 服务 origin，配合同一专用回调 token；其值不来自模型或任务输入。可选的 capture origin/token 为独立部署覆盖，必须与 API 的身份配置一致。

执行器先调用服务专用 `/internal/v1/observation-captures`，等待事务提交回执，再调用提取模型。该路径不是浏览器会话 API，不经前端 SPA 回退；内部 HTTP 服务必须处于受控网络，对外使用 HTTPS。发布的一次性回调使用同一配置源、不同固定路径和密封上下文。

恢复不能打开可能自动继续生成的供应方历史 UI；只使用只读历史读取操作，不执行继续生成。服务端清理通过 `/v1/sessions/{id}/cleanup-conversation`，删除前调用固定服务回调 `/internal/v1/provider-conversation-cleanup/authorize`。回调的密封票据绑定原身份、会话、任务及两个租约；用户、模型和执行器请求不能直接声明“已授权”。这些都是后台操作，没有人工审批步骤。

迁移 `0042_provider_conversation_cleanup.sql` 与对应 repository 提供清理候选账本：从已存快照推导归属、去重、租约领取、未知结果只读核对和独立退避。重试计数仅用于退避，不设次数耗尽后永久停止清理的门槛。有界 UUID 游标扫描补登记已保存但未入账的快照，再领取到期项；项目暂停不停止清理。数据库模式配置浏览器及服务回调后装配扫描器，内存开发模式不启动该服务。

领取不是删除许可。调度器先取得发布/测量共用的账号执行锁，检查完整证据后才恢复浏览器；缺失证据不会启动浏览器或重新提问。实际删除回调再次以数据库锁校验租约、原账号、归属和活动引用。执行器核对活体账号后，完整分页读取当前消息清单，按消息 ID/角色排序后与本地证据摘要对比；存在新增消息、缺失消息、未知状态、重复 ID 或不完整分页时保留会话。删除请求必须在绝对租约截止前预留完整请求及关闭时间；超时或模糊回执只进入只读核对，不能把任意 404 当作删除成功。关闭未确认时不提前释放账号锁。

消息清单核对能识别追加回合，但不证明相同 ID 的正文未被供应方原地修改，也不消除最后一次读取与删除之间的供应方编辑竞态。现有接口尚无已验证的条件删除/修订号语义，不能宣称实现远端原子快照删除。旧记录缺少原身份、完整证据或可靠消息清单时保持待恢复；归档能力、历史证据补齐与重新解释仍需单独实现。源码接线、夹具和隔离实库回归不代替部署与真实账号删除验收，当前实际交付状态见工作日志。

## 验收

- 单任务的测量与提取会话均登记；用户原有会话不受影响。
- 供应方已有回答但解释失败时，原始证据仍可读，重跑解释不增加测量请求。
- 未得到持久化回执不得删除；入库失败、API/执行器重启和响应丢失可恢复。
- 清理失败、账号失效与删除超时独立重试/核对，不引发重新测量。
- 删除或归档后仍可从本系统读回原回答、引用与审计来源。
- 没有实际实现/验证删除能力的适配器不得报告远端会话已经清理。
