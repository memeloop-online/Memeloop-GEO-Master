# 已保存测量记录的重新解析

## 用户流程

在测量记录详情中，存在已保存原始响应时可选择“重新解析”。服务使用项目“模型与 AI → 测量结果解析”的 API 模型，不再向被测平台发送测量问题。答案、引用、解析模型和时间独立保存；原测量状态、采样时间和统计分母不改变。

实时测量仍可优先使用已登录网页账号解释回答。历史重解析本增量只使用项目 API 解析路由，不能将其描述为重新测量或新的平台反馈。

## 服务与证据

- 用户接口：`GET/POST /api/v1/projects/{project_id}/channel-targets/{target_id}/attempts/{attempt_id}/analyses`。
- POST 只需 `idempotency_key`，可选 `capture_id`；服务从持久记录确定来源、摘要和原采样时间，不要求用户填写技术字段。
- GET 返回可解析来源、分析版本及游标。按创建时间与版本 ID 倒序稳定分页，最新版本保持可见。
- 解析提示词复用实时解析模板。AI 解释内容语义，执行器端仅复用原文定位与结构核对；没有供应商内容规则解析器。
- 服务内部通过认证的 `/v1/observation-analyses/ground` 核对模型候选与原文字节摘要。该端点不打开浏览器、不访问供应商、不持有用户登录态。
- 来源必须与租户、项目、目标、执行和账号绑定。执行超时形成的占位 unknown 不应掩盖已经独立持久保存的真实来源；明确的夹具来源仍不可当成真实证据。
- 保存实际解析模型、项目配置修订、用量和独立结果；未通过核对时不展示候选内容为已确认答案。隐私字段过滤与实时解析共用。

## 幂等、中断与恢复

相同提交键复用同一版本，由原子 claim 防止并发重复推理。执行限时 150 秒；超过 180 秒的 queued/running 版本在当前目标的 GET/POST 中终结为中断，撤销旧 claim，迟到结果不能覆写。不会自动重发模型请求；用户可在失败后显式创建新解析版本。

这是按访问收敛的中断处理，不是完整后台恢复扫描。进程停止后，无访问的历史版本不会立即更新状态。本增量不授权远端会话删除。

### 失败含义

持久失败代码区分来源不可读、模型未配置或访问被拒、上游 HTTP 状态、传输失败、响应格式不支持、超时及原文核对服务不可用。页面使用固定中英文提示，不回显上游错误正文；服务不可用不会一律要求用户重填密钥。未知或旧版原因保留一般失败提示，不能根据耗时猜测故障。

未收到可规范化的模型完成响应时，实际模型仍为空，不能用请求模型或设置页默认值补齐。已收到响应但后续候选或审计校验失败时，保留合法的实际模型、配置修订与用量，丢弃不合格候选。输出截断、过大、工具调用或无效内容分别记为未核验，不转成已确认答案。这些诊断不会自动再次调用模型。

## 信源和报告投影

信源与渠道建议读取当前执行的一个有效回答：有来源核验通过的已完成解析时，采用截止时刻内最新的有效解析，否则保留原有可信观测。较新的失败解析不抹除旧有效解析，同一问题的多个版本不合并引用或重复计数。展示独立的解析计数、模型、时间和版本依据，原执行状态和统计分母不变。优化用途仍按不可变问题用途与项目作用域过滤。

报告将这类结果放入独立的 `supplementary_measurements`，不加入冻结测量目标的分母。独立话题须落在报告的采样窗口；原始来源保存时间及解析完成时间都不能晚于报告证据截止。截止后完成的解析只进入后续显式更正，不能回填已保存的首版报告。预览、CSV 和 PDF 使用同一份独立证据与实际模型出处；旧快照重放保持原样。

数据库按指定执行批量选择最新有效解析，来源绑定和字节摘要由共享只读服务复核。索引可用性回归不代表总体吞吐或百万记录容量已验收。

## 验收范围

需分别验证来源发现、跨项目拒绝、重复提交、失败与中断、答案/引用核对及刷新后持久读回。自动化回归不替代真实演示；单次离线解析成功不代表用户界面的闭环已完成。
