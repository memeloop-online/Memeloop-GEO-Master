# 不可变周报 PDF 导出

P14 的正式报告详情提供“下载覆盖与证据 PDF”。此功能直接读取当前已保存快照，不重新汇聚、不产生报告修订、不推进周期，也不发送或重新测量内容。临时预览没有 PDF 导出入口。

## 数据与交互

- 使用所选 `ReportSnapshot` 内嵌的全部证据；独立证据面板请求失败不改变导出内容。
- 导出报告/项目/周期身份、修订及更正关系、时间窗口/时区/截止/证据水位、输入摘要和清单版本、三类覆盖、独立平台/比较组、结论及证据附录。
- 保持未知分母、零分母、未封存、缺测、未提及、拒答、未知发布等状态，不重新计算趋势或合并不同测量协议。
- 快照尚未提供完整资产明细、费用与下一轮动作，PDF 明确说明缺口；导出文件可用不等于完整效果报告验收。
- 生成期间禁用重复点击；失败可重试。切换报告、项目或离开页面时取消未完成导出，不能下载旧作用域内容。
- 文件为 `application/pdf`，命名 `report-{report_id}-r{revision}.pdf`；下载后释放临时 object URL。

## 实现

`apps/web/src/pages/reportsPdf.ts` 按显式字段输出，不序列化整个未知对象，不渲染任意 HTML、不访问正文中的链接。模块按需加载，`pdf-lib` 和 `@pdf-lib/fontkit` 均锁定版本。

字体来自同源静态资源 `public/fonts/NotoSansCJKsc-Regular.otf`，在 PDF 中完整嵌入 CJK 字体。实际渲染验证发现当前库的 CFF 子集化会导致中文方框，因此采用完整嵌入，代价是每份文件约 14 MB；不能用“中文可被提取”代替可读性验证。源字体保持上游原样，许可、固定来源和摘要见同目录 README/OFL。无需外部字体服务或用户机器预装字体。

A4 分页根据字体实际宽度拆行，长连续标识符也不能超出页宽。未支持字形以明确的 Unicode 码点标记保留，并在文档说明，不静默输出空白字形。长报告分批让出事件循环并检查取消。

当前字体还需关闭 `locl` 本地化字形替换：原始 ASCII 数字在部分长标识符上下文中会被替换为私用区字形，虽然肉眼可见却破坏 PDF 文本提取。字形宽度计算和实际编码使用相同配置，验收保留含数字的长证据尾部标识，不通过替换测试文本绕过问题。

## 验证边界

单元测试覆盖实际字体与 PDF 文件生成、分页、元数据、下载、异常和取消；页面测试覆盖正式/预览分离、失败重试、重复点击、作用域切换和独立证据请求失败。

独立验收使用合成快照生成 PDF，再用另一个解析器核对中文、状态、最后一项证据与分页，并渲染页面供查看。只有工作日志记录的实际执行才算通过；合成报告不能替代真实发布/AI 渠道效果验收。

运行 `node scripts/verify-report-pdf.mjs`，设置仓库外绝对输出目录 `GEO_REPORT_PDF_OUTPUT_DIR` 和已构建解析服务 JAR 的绝对路径 `GEO_REPORT_PDF_PARSER_JAR`，使用 Java 21 或以上。可选 `GEO_REPORT_PDF_JAVA` 指向本机 Java。Linux CI 运行同一脚本并提供 `report-pdf-synthetic-<sha>` 合成 PDF/PNG artifact；不接收真实客户报告作为 CI 夹具。
