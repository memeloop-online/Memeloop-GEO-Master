# 持久浏览器占用与登录恢复

本增量把浏览器实例凭证接到登录、模型发现、测量、发布、发布查回和远端会话清理的实际调用路径。它是顺序账号接入与固定网络绑定的共同基础，不代表批量登录调度、代理池成员分配或真实出口检查已经完成。

## 同一账号的一致占用

迁移 `0052_browser_operations.sql` 保存操作、真实调用作用域、用途、浏览器会话与实例、加密网络快照、状态和下次对账时间。操作取得与原有 `(operator, account)` 执行预留共用同一事务入口：

- 登录可使用运营商作用域，不伪造客户项目。
- 已有执行预留只能由相同持有人绑定操作；登录不能越过正在进行的发现或执行。
- 浏览器操作未确认释放时，预留过期也不能被接管，旧释放方法不能删除它。
- 启动之前先持久记录操作，再标记已请求启动；启动参数从操作专属认证上下文的密文快照读取，不临时换用当前代理。
- 只有尚未请求启动的操作可直接释放；请求已经发出后必须得到原实例、原会话的精确释放凭证。旧操作重放不能释放后继占用。

领域、内存与 PostgreSQL 使用相同状态语义。数据库重建仓储后读回原操作，不能靠进程内 Map 恢复归属。

## 登录与凭据保存

项目账号和运营账号池均先保存登录引用再发起浏览器启动。同一认证 Cookie 的重复启动可读回原操作与登录引用，不创建第二个浏览器；其他认证会话不能直接接管。

API 重启后的桌面授权从持久引用和当前权限恢复，仍使用标准远程桌面客户端。登录已过期或关闭失败时保留可重试的引用，不把普通 404 映射为释放完成。尚未启动就中断的准备记录提供取消恢复路径，不声称已存在可用桌面。

完成登录先验证网站身份，再提交凭据，最后关闭浏览器。凭据提交与操作占用校验是一致的事务边界：

1. 只允许确实持有账号的登录操作在已请求启动状态提交。
2. 校验账号仍启用、平台／既有身份／旧凭据未改变。
3. 只更新经验证身份、连接状态及加密 session，保留分组、代理和其他元数据。
4. 取消或新登录先完成时，迟到的旧验证结果报冲突，不覆盖新凭据。

PostgreSQL 在同一事务中锁操作与占用后保存；内存实现保持同样的锁定顺序。登录引用重复保存保留首次创建时间，不能借重试延长过期窗口。

## 后台恢复

后台每轮读取最多 100 条到期操作，并行执行有界关闭；该页大小不是用户任务的并发上限。准备中且没有请求启动的操作可以释放；其他操作仅向记录的实例发起关闭，不创建替代浏览器、不重新提问。

关闭失败或实例不符保留占用并延后检查，使其他待处理记录仍可推进。实例内资源释放与供应商对话删除是不同结果，不能互相替代。

## 升级与未完成边界

- 先部署支持实例凭证的执行器，再部署迁移和 API。切换前须排空旧 API 的启动／执行工作，不能让不认识持久占用的旧版本与新版本同时派发。
- 保留的旧登录引用如果缺少实例来源，会阻止新的浏览器启动。不能以过期时间或当前实例补造证明；需确认旧运行环境及其浏览器已终止后，再做受控历史整理。
- 实例不符时不自动释放。跨副本稳定路由及运行环境终止证明仍待实现。
- 客户与运营账号仍沿用既有代理选择逻辑；操作只固定本次网络快照。账号活动／待生效绑定、历史结果按原网络恢复和代理池自动分配仍未接通。
