## 1. 交付边界

用户从 P00 输入任意话题、网址或资料开始；无企业资料也能提出问题并独立测量。
正常路径为话题/问题 → 知识与页面证据 → 内容版本 → 发布 → 匿名公开验证 → 索引观察 → 独立 AI 引用观测 → 周报与增量。
各环节独立保存证据，不以某一环节成功推导其他环节成功。
外部创作者平台的客户自有账号与运营账号池是第一发布面，不要求客户自建 CMS 或站群。
客户已有官网仅在接通具有写权限的 CMS、Git 或 patch 适配器后支持自动修改与回滚。
未接写能力的官网支持诊断、建议与导出，不能把生成 patch 说成已修改网站。
运营池由资源管理员授权分配；普通客户不取得共享账号凭据。
不增加人工审批、发布确认、能力放行开关或按次执行按钮。
用户只承担不可代办的登录、授权与验证码；失败分支由系统阻断、解释并在条件恢复后自动继续。
权限、预算、内容检查、平台限制和范围校验仍是服务端硬约束。

## 3. SEO 采集与诊断

### 3.1 受限 raw / rendered 抓取

`raw` 保存 HTTP 响应与解析结果；`rendered` 使用维护中的浏览器栈取得脚本执行后的 DOM。
两种模式独立记录摘要、时间、状态和差异；不得用 raw 结果冒充渲染后可见性。
优先复用维护中的 HTTP、HTML、robots、结构化数据和浏览器库，先评估许可证、维护及集成成本。
产品只实现任务编排、授权范围、证据规范和规则适配，不另造浏览器或解析器。
任务冻结精确主机、可选路径前缀、种子、深度、页数、字节、时间及同主机并发上限。
首次同域抓取沿用产品规格的最多 200 页，后续增量检查；不另设要求用户填写的技术配额表单或固定执行并发门禁。
部署资源保护与套餐范围由服务端配置，模型不能提高；未覆盖页面保留 partial 原因。
默认遵守 robots；抓取失败、禁止或不可判定分别记录，不静默绕过。
robots 允许抓取不等于获得修改或账号权限；站点范围授权与写权限分别校验。
取消停止新出站及新页领取，正在保存的证据可完成；重启按已冻结队列恢复而非重抓全部页面。
页面导航与链接发现严格遵守冻结范围；rendered 模式同样约束脚本、iframe、XHR、图片和下载请求。
渲染所需公网 CDN/脚本/XHR 等子资源使用独立请求数、字节和时间预算，逐次校验实际请求与重定向的 SSRF 边界。
子资源加载不将其 URL 加入页面发现队列，不赋予跨域页面抓取权限；iframe 文档导航仍受页面范围限制。
依赖被阻断或超预算时记录 `rendered_partial` 及依赖缺口，只降级受影响的渲染结论。
已取得的 HTTP 正文、状态和 robots 等证据仍有效，不因单个渲染依赖失败将整份报告改为 unknown。
默认拒绝登录态页面，不附加发布账号 Cookie；抓取连接与渠道登录上下文隔离。
公开页面的只读诊断输入网址即可开始，不要求额外 DNS 所有权验证或人工审批；站长私有数据和官网写入才需要相应连接权限。

### 3.2 网络安全

URL 仅接受 HTTP(S)，拒绝用户信息、非许可端口、混淆主机、无效编码及不支持的协议。
DNS 每次连接和每跳重定向重新校验；阻断 loopback、私网、链路本地、保留地址和云元数据。
同时覆盖 IPv4、IPv6、映射地址、DNS 重绑定及代理解析差异；连接实际目的地址必须符合校验结果。
链接、canonical、sitemap 和 hreflang 的外域值可以记录为证据，但不能自动扩张允许抓取范围。
页面重定向跳出授权同域/路径范围时记录边界并停止跟随；新增范围必须走独立授权修订。
站点抓取策略只限制 SEO 出站执行器，不改变应用自身内网演示访问、数据库或合法内部服务调用。
证据正文与 URL 查询参数按敏感信息策略处理；凭据、私人入口和真实运行上下文不进入公开仓库。

### 3.3 诊断规则

每项 finding 保存规则版本、严重程度、受影响页、证据位置、建议与可自动修复标记。
检测状态码/跳转链、循环与死链、robots、meta/X-Robots noindex、canonical 和索引可用性冲突。
检测 sitemap 覆盖/无效项、hreflang 互指/语言关系、标题/描述、重复正文及重复标题。
保存站内入链/出链图、孤立候选页和深度；抓取未覆盖完整站点时标记图不完整。
structured data 先校验语法和适用 schema，再指出内容不一致；通过校验不保证富结果展示。
重复页面按正文规范化摘要和相似度规则分组，保留原版本，不能擅自合并 URL。
建议与修改分开：诊断可完成但没有写权限；页面 HTTP 200 不证明搜索收录。

### 3.4 站长工具与机会数据

优先连接站点所有者授权的官方数据接口；OAuth/密钥进入服务端凭据库，模型只见连接引用。
同步记录 property、权限、来源、日期、时区、维度、分页、数据延迟和提供方限制。
保存查询/页面的点击、展示、CTR、平均位置及适用维度，不把聚合平均值解释为每次排名。
站长工具的搜索展示属于该来源/属性/日期范围，不等于 AI 回答曝光或全市场搜索量。
外部关键词估算必须标 `estimated`、方法与日期；AI 预测的问题必须标 `model_predicted`。
`observed`、`estimated`、`model_predicted` 不混合求和，也不以空值替代零。
查询按意图/主题聚类，再关联已存在页面、知识来源和内容机会；聚类模型及输入版本可回溯。
模型预测、公开页面观测和授权站长实际查询分别保存来源记录与用途，不能只用同一自由文本字段区分。
机会采用后持久关联内容 revision、渠道变体、问题集版本及适用 cycle，记录采用理由与原证据引用。
服务端按租户、项目、用途和授权筛出 eligible evidence refs；聚类、生成及每次后续读取均重新校验。
冻结评估题、逐题答案以及可还原其内容的摘要/派生字段不得进入优化工具，不能依赖模型自行遵守。
首次实现确定性标准化、精确关联及有界模型聚类，不因尚无搜索量供应商而编造指标。
无授权数据时允许使用页面诊断和模型建议，但卡片明确未连接实际搜索表现。

### 3.5 传统搜索结果测量

用户可从 P00 或测量详情输入任意关键词直接发起传统搜索测量，不以企业资料、优化周期、AI 账号或站长授权为前置条件。
可选目标 URL/域名用于命中和排名跟踪；未指定目标时仍可保存结果列表，不要求补齐企业资料。
复用现有租户/项目、版本化问题集合及用途隔离、后台领取、幂等、取消、证据存储和共同周报；P00 与详情页读写同一持久资源。
采用供应商中立的 `SerpObservation` 与 `SerpResult` 契约及薄引擎适配器，不把 AI 回答的 `citations` 改解释为自然排名。

- 每次观察冻结 query、engine、数据来源/观测面、国家/地区及适用城市、语言、设备、登录/个性化条件、计划与实际观察时间、结果深度、协议和连接器版本。来源无法保证的条件明确标未知，不用请求参数冒充实际生效条件。
- 结果保存原始及规范化 URL、host、适用域名及规范化规则版本、标题、结果类型、页码/位置和自然排名。广告、精选摘要、地图和搜索页 AI 摘要单独分类，不占用或冒充自然结果排名；重复 URL 的展示位置与去重聚合分别保留。
- 原始响应或页面证据受控保存并带摘要、采集时间和结果定位；记录请求关联、分页/截断、实际覆盖深度、解析版本及来源限制。原证据不进公开仓库；重解析产生新版本，不改写既有观察或重复采样。
- 区分已命中、成功覆盖指定深度但未命中、partial、挑战/必要登录、missing、failed 和 unsupported；未命中的排名为空并显示覆盖深度，不写零或虚构末位。失败不算未命中，未命中不证明未收录；预算或分页不足保留 partial。
- 自然排名、搜索页特殊结果、AI 回答提及/引用、官方站长 `SearchDataset`、官方索引状态分别存储和展示。站长平均位置不是某次 SERP 排名，搜索展示不是 AI 曝光；估算量和模型预测不混入真实观测。
- 趋势只比较协议与目标匹配规则兼容的样本，显示采样时间、样本分母、缺测及覆盖深度；目标 URL/域名匹配规则固定版本，协议变化单列，不据前后波动宣称发布导致提升。

首个引擎/数据源暂不预定：实施前核验官方接口或合规数据服务的访问条件、地域/设备覆盖、证据可追溯性、费用、限流、维护和许可证，再记录可验证的适配选择依据。
优先复用维护中的客户端或浏览器栈，只实现产品授权、调度和证据适配；缺少合法可用数据源时明确 blocked/unsupported，不用模型生成排名，不绕过访问限制。
首包验收为一个已选引擎的任意关键词受理 → 后台采样 → 原始证据与排名持久化 → 刷新读回 → 趋势/共同周报；同时覆盖分页截断、缺测、跨租户拒绝、重启及重复事件不重复执行。
单元/合成数据测试、真实数据源验证和真实 UI 验收分别记录；上述契约不表示传统搜索测量已实现。

## 4. 最小领域模型与 API

复用现有 Project、KnowledgeRelease、ContentRevision、媒体、DistributionManifest、PublicationIntent 和 ReportSnapshot。
新增实体必须携带服务端作用域、schema_version、created_at；不可变记录使用摘要引用而非复制秘密。

| 实体 | 最小字段与约束 |
|---|---|
| `SiteScopeRevision` | 精确主机/路径、权限依据、预算、revision；任务绑定冻结修订 |
| `SearchConnection` | provider/property 引用、授权状态、加密秘密引用；不向普通响应暴露 token |
| `CrawlRun` | scope_revision、mode、limits、状态、checkpoint、lease/fence、取消版本 |
| `PageSnapshot` | crawl/page key、URL、安全规范化 URL、fetch/render 时间、状态、内容摘要、证据对象 |
| `SeoFinding` | snapshot、rule_version、证据位置、类别、severity、修复范围 |
| `SearchDataset` | connection、日期/维度、页游标、完整性、来源/观察类别、不可变数据版本 |
| `OpportunityCluster` | 合格来源引用、聚类版本、页面/知识绑定、用途；预测/公开观测/实际查询独立来源 |
| `OpportunityAdoption` | cluster、eligible evidence refs、content_revision、variant、question_set_revision、适用 cycle、采用理由 |
| `ContentDistributionRequest` | 冻结 revision、渠道/账号、请求摘要、稳定幂等键、既有 intent 引用；不自建发布状态机 |
| `SiteChangeSet` | 原快照/远端版本、内容 revision、适配器版本、diff 摘要、校验结果、回滚引用 |
| `SiteChangeAttempt` | change_set、稳定发送键、租约、远端版本/事件关联、未知状态 |
| `IndexObservation` | asset、观察类型、provider/surface、适用查询/时地、观察/接收时间、状态、证据引用 |

HTTP 均位于现有 `/api/v1/projects/{project_id}` 下，使用会话权限及现有 CSRF/Origin 防护：

```text
POST /site-scopes
GET  /site-scopes
POST /seo/crawls
GET  /seo/crawls/{id}
POST /seo/crawls/{id}/cancel
GET  /seo/crawls/{id}/pages
GET  /seo/crawls/{id}/findings
POST /search-connections/{id}/sync
GET  /seo/search-datasets/{id}
GET  /seo/opportunities
POST /seo/opportunities/{id}/adoptions
POST /content-distribution-requests
GET  /content-distribution-requests/{id}
POST /site-changes
POST /site-changes/{id}/apply
POST /site-changes/{id}/rollback
GET  /site-changes/{id}
POST /index-observations
GET  /index-observations
```

写请求带 `Idempotency-Key`，修改配置带 expected revision；同键同请求复用，同键异请求 409。
异步命令返回 202、operation/resource ID；GET 不启动任务或外部副作用。
列表用绑定作用域的 keyset 游标与硬页大小；无权限资源不泄漏存在性。
状态变更、outbox 与事件在同一事务保存；消费者重复领取不造成重复发送或重复费用。
抓取/同步状态：queued → running → succeeded / partial / failed / cancelled；必要授权缺失为 blocked。
写入状态独立保存 prepared、queued、sending、unknown、applied、failed；unknown 仅允许只读查回。
`asset_observed`、`public_verified`、`index_observed`、`ai_cited` 是独立证据维度，不是一条自动升级链。
租约过期用 fencing 拒绝旧写入；多副本恢复只读 ledger，不依赖内存状态或 JS checkpoint 判断副作用。

## 5. 发布纵切与富文本

### 5.1 已知实码边界

知乎已有身份校验、纯文本 publish、匿名全文及归属 lookup，但尚不能宣称真实账号闭环验收完成。
百度提交后必须记录 unknown；lookup 当前 unsupported，不能自动补成成功。
小红书当前只有 identity，publish/lookup 均 unsupported。
X 尚未接入 allowlist、API 与 adapters，必须作为独立后续适配包。
正式分发 `prepare_variant` 当前拒绝 schema 2 和全部 media；runner 的发送输入仍只有 title/body。
`prepare_rich_variant` 尚未连接正式 outbox；编辑器、ZIP 导出或纯文本发布不代表富文本交付。
现有 bootstrap 能力证明机制保留，不增加人工开关；能力仍按真实来源、连接器版本和格式投影。

### 5.2 正式载荷与匿名验证

先完成已有知乎纯文本路径的真实纵切，再接同一链路的版本化富文本与图片；二者分别验收。
扩展正式变体、意图、outbox、执行绑定与 runner 的同一载荷 schema，不旁路 outbox 单独发送。
载荷冻结 content_revision、variant_revision、format/schema、结构树摘要和媒体清单摘要。
媒体项至少包括租户对象引用、字节摘要、MIME、尺寸、alt、顺序和用途；上传 URL 短期授权且不进入日志。
图片资产在发送前验证归属、可读性和平台约束；媒体失败阻断该变体，不静默删除图片或改发纯文本。
平台无法表达的节点在变体准备时明确 unsupported 或生成独立可追溯降级版本，不修改冻结源内容。
发送前验证账号身份、能力版本、授权、预算、内容版本及媒体可用性；身份变化不得换账号继续。
匿名验证禁用账号 Cookie，并保持规定出口；核对公开 URL、作者归属、标题、全文与支持的结构/图片。
平台合理变换通过版本化规则比较；只检查标题、HTTP 200、登录后可见或编辑页截图不能证明公开交付。
证据分别记录提交回执、公开读回、结构/媒体校验；富文本能力不能由文本摘要一致推导。
发送因果关联必须绑定原 execution/attempt、提供方资产 ID 或可信提交事件及时间窗口。
无因果证明的同正文资产仅追加 `asset_observed`，原发送仍 unknown；不重发、不覆盖原尝试。
查回任务复用既有加密执行绑定和只读 lookup；没有候选、歧义或 unsupported 均保存原因并退避。
历史原尝试与报告不修改；迟到因果证据以追加对账记录形成当前投影，并以新更正报告表达。

### 5.3 官网写入与回滚

适配器按能力声明 read、patch、publish、lookup、rollback，不把有读权限误标成有写权限。
change set 保存 base ETag/commit/revision 和目标 diff；执行前复核，不覆盖用户并发编辑。
冲突重新诊断并生成新版本，不强制覆盖；相同 change set 重复事件最多产生一次实际写入。
回滚是新的条件写入，绑定原变更及当前远端版本；当前版本不匹配时阻断而非覆盖后续工作。
Git/CMS 的既有保护规则仍生效；没有直接写权限时只生成可导出成果，不要求用户为产品新建审批流程。
变更成功后重新抓取公开页面；索引与 AI 观测仍通过独立任务获取，不能承诺自动收录或引用。

### 5.4 本篇立即分发与后续默认范围

“把本篇发到指定渠道”与“以后默认包含该渠道”是独立意图；前者不得顺带修改项目默认范围。
意图明确时直接执行已授权动作，无需确认；正文版本、目标或意图真正歧义时只问一次必要问题。
当前单篇即时分发尚无完备正式命令；新增薄 `ContentDistributionRequest`，受理时固定当前 content revision、渠道及账号。
复用现有变体、PublicationIntent、outbox、发送前检查和只读查回，不建立第二套发送账本或发布状态机。
请求重试复用稳定键；发送前按固定版本、目标、账号及格式检查已有有效回执或在途/未知意图并关联。
已有效发布则复用；在途等待，unknown 只查回；超时、对话重试和重复事件不能触发第二次发送。
更改后续默认范围沿用既有项目修订 API 和 `distribution_scope`；不追改当前或已冻结周期。
单篇动作在报告单列；仅按执行前已明确的冻结覆盖匹配规则关联原覆盖项，不改变分母或事后补算。
请求、采用关系与报告投影均复核同作用域资源；跨项目 revision、账号或原意图引用必须拒绝。

## 6. 周报与效果口径

SEO 记录页面技术状态、实际站长表现和独立索引证据；GEO 记录固定协议下回答、提及及引用样本。
外部渠道公开文章同样进入 SEO 只读观测和共同 ReportSnapshot，不以官网写权限或 CMS 接入为前置条件。
匿名可读、允许索引信号、某查询/时间/地区的 SERP 命中、官方索引状态和 AI 引用分别保存，不互相替代。
允许索引信号仅说明已观察到的 robots/noindex 等条件，SERP 未命中也不能直接判定未收录。
站长连接仅能查询其实际授权 property；第三方文章无官方索引权限时该类型为 unsupported，不借本站连接查询外域。
公开读取与合法 SERP 观测可独立进行；某类型 unsupported 不抹去其他已取得的证据。
AI mentions 只能称为“本次样本中的提及次数/比例”，必须显示样本分母、缺测、模型、时间和观测面。
不能把采样 mentions、引用频次或模型预测转成真实用户曝光、访问量、平台权重或因果增量。
报告冻结覆盖清单与截止；发布未知、公开资产存在、收录未知、引用缺测各自保留。
比较前后变化时列出协议、样本、日期和内容版本差异；无对照设计不声称提升由发布导致。
下一轮只使用允许优化的证据，冻结评估逐题内容及派生信息不得泄漏给优化器。
复用未变化内容和原发布意图；新周期覆盖独立计数，但不能对复用资产重新发送。

## 7. 迭代任务与验收门槛

### I1：已有发布路径真实闭环

复用持久账号、能力 bootstrap、正式分发及查回账本，补齐真实知乎发送和匿名完整读回证据。
同时交付薄单篇分发请求、公开资产基础 SEO 观测与共同周报投影，不等待官网写入迭代。
验收从实际 P00/详情页面开始：用户完成必要登录后自动发送，离开/返回页面显示同一任务。
验证账号归属、内容全文、匿名可见、发送仅一次；实测未知结果没有“重发”恢复路径。
故障注入覆盖发送前崩溃、发送后丢回执、重复事件、重启及多副本领取。
单元、夹具、CI 和真实外部验收分别记录；不得用绿色 CI 替代本门槛。
最小 E2E：聊天指定当前 revision 分发且默认范围不变 → 超时重试仅发送一次并查回 → 公开 SEO 观测 → 共同周报且冻结分母不变 → 优化工具拒绝 heldout 证据读取。

### I2：富文本与图片正式分发

贯通 schema 2 的变体、载荷、outbox、执行器及匿名校验；补媒体过期/失效恢复和格式能力证据。
实际页面验收 AI 生成/插图 → 详情读回同一版本 → 自动发布 → 匿名全文/图片/归属验证。
跨租户对象引用、图片摘要替换、旧版本重放、不支持节点及附件失效必须被拒绝且不重复发送。
同时补发送因果追加对账，验证旧 unknown/旧报告字节不变，迟到证据可单独追溯。

### I3：SEO 只读诊断与站长数据

交付范围配置、raw/rendered 抓取、取消/恢复、规则诊断、站长连接及查询/页面聚类。
完善外部公开资产的分类型 SEO 观察、共同周报，以及机会到内容/变体/问题集/周期的持久采用关系。
用受控公开页面验证重定向、robots/noindex、canonical、sitemap/hreflang、重复与结构化数据。
安全测试覆盖内网/IPv6/重绑定/跨域跳转/浏览器子请求；不破坏内部演示登录访问。
验证公网 CDN 正常加载但不扩页队列、阻断依赖仅造成 rendered_partial、有效 HTTP/robots 结论仍保留。
跨租户/用途读取、heldout 派生摘要及撤权证据必须被拒绝；无外域站长权限显示 unsupported。
实际浏览器验证 SEO/GEO 标签、空数据/部分抓取/分页、AI 发起与详情读回、授权失效和重启恢复。

### I4：官网写入及独立效果观察

至少接一种已授权 CMS/Git/patch 适配器，验证有写权限自动修改、公开复查和条件回滚。
无写权限仅诊断/导出；并发页面修改、重复命令及未知写入不得覆盖或盲目重试。
官网变更接入 I1/I3 已建立的独立观察和共同周报，补下一轮增量；真实缺测在卡片、报告和导出一致出现。
验证截止前后、旧周期复用、来源撤销、权限撤销和跨租户读取；任一 HTTP 成功不得自动标记收录/AI 引用。

### I5：独立渠道扩展

百度、小红书、X 各自独立交付身份、格式、发送、只读查回、匿名验证及故障恢复，不共享完成声明。
每包先评估平台规则、官方接口及维护中的可用集成；适配能力缺失明确 unsupported。
每个平台分别通过真实页面、真实账号、公开证据、重复事件、重启和未知不重发验收后才升级能力。
完成证据只记录通用行为和脱敏结论；账号、域名、部署目标、凭据与截图保持仓库外受控保存。
