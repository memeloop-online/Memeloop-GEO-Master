# 运营账号接入与出口分配

状态（2026-10-12）：单账号远程登录、资源组、项目名称分配、加密逐行导入、代理库存和固定网络绑定已部署；当前 API／Web 为 `202b2cb`，执行器 `8391fad`。持久顺序登录已提交 PR #26、未部署，界面第二轮阻断修正后已由协调者复核并通过 109 项测试，不增加第三轮独立审查。后续 CI 暴露的勾选就绪竞态已补确定性测试，修订提交的 CI 待验证。资源管理员访问、真实导入及供应商账号仍未验收；经验证的自动填表、自动代理分配和实际不同出口检查未完成。产品规格书保持不变。

## 操作路径

目标路径：后台账号池 → 粘贴或上传用户名／密码对 → 检查导入结果 → 逐个登录 → 核验并保存连接 → 分配到项目。代理池为不同账号分配经检查的不同出口，独立于导入交付。

- 已实现清单支持平台、用户名、密码、显示别名及资源组，并提供逐条添加。代理池选择是后续能力，当前接口不接受代理池字段。
- 导入只建立待登录记录，不把用户名当作平台身份；身份由已登录网站的账户响应确认。
- 当前部署支持导入后逐行打开既有远程登录；持久顺序调度及中断恢复已在 PR #26 实现，尚未上线。扫码或验证码在标准 noVNC 窗口接续，不重复建账号。
- 经验证的网站表单适配尚未实现，当前不能承诺已保存凭据自动填入。后续通过维护中的浏览器自动化库填写，不新增远程键盘、剪贴板或文本注入协议；现阶段在标准远程页面手动登录。
- 后台列出待登录、登录中、已连接、需要重新登录和失败原因。模型菜单、联网测量、发布及会话清理能力各自显示，不由登录状态推导。
- 千问、元宝加入接入范围；实现前核验当前官方网站入口及身份响应。仅能打开页面时不声明账号核验可用。

## 导入与凭据

- 导入请求包含稳定 `import_key`，每行包含稳定 `row_key`；服务端在 operator 作用域保存逐行结果。相同键和内容重试复用结果，同键异内容报冲突，失败行单独重试。
- 接口返回账号引用、行状态和脱敏错误，不返回密码、Cookie、session 或代理口令。列表不显示完整用户名；详情按已有资源管理员权限查看必要账号信息。
- 用户名／密码是接入凭据，已验证浏览器 session 是执行凭据，两者独立加密和版本化。复用现有 operator 作用域密钥管理；不把凭据放入账号 metadata。
- 上传解析内存有界；原文件默认不持久保存，任务只保存必要的加密行数据。预览、错误、审计与日志不得包含明文密码或完整原行。
- 账号分组、停用、凭据轮换和项目分配复用现有服务。项目选择使用 operator 授权的名称目录，取消手填租户／项目 UUID。
- 不修改现有首次初始化命令来绕过其一致性检查；已有部署新增资源管理员需单独的受控身份配置操作。

## 代理池

以下是完整目标契约；PR #21 库存与不可变加密修订、PR #24 手动固定版本绑定已部署。自动分配及不同出口检查仍待实现，库存或手动绑定不能替代这些能力。

- 池成员保存协议、地址、端口及加密认证凭据；探测结果只保存连接状态、延迟、最后检查时间和脱敏出口标识。
- 账号绑定固定成员及绑定版本。登录、恢复、模型发现、测量、发布和远端会话清理使用同一版本；不逐请求轮换。
- 支持导入时自动分配不同成员、手动指定成员、查看占用及批量检查。成员数不足或实际出口重复时明确显示，不能声称已获得不同出口。
- 网络地址不同不证明出口 IP 不同。通过运营者配置的探测端点确认实际出口，真实网络配置及结果不进入公开文档。
- 更换绑定在在途任务结束后生效；任务保留原绑定引用供结果查回及清理。代理故障不静默改走默认网络，不通过不断更换 IP 重试已被平台拒绝的操作。
- 代理只负责网络路由与会话稳定性，不保证账号不会受到平台限制。网站验证由账号持有人完成。

## 交付与验收顺序

1. 修复管理员角色映射，已有资源管理员能够进入账号池；普通项目管理员仍不能读取运营池凭据。
2. operator 范围项目目录和选择器，资源组及账号筛选，消除手填内部标识。
3. 加密凭据导入及逐行幂等／重试已部署、待真实验收；随后实施持久顺序登录队列及中断恢复，不能把浏览器组件状态视为队列。
4. 代理池、固定出口分配及真实连接检查；验证代理失效、重复出口、凭据轮换和任务中途更换绑定。
5. 千问、元宝分别验收真实登录、身份保存、刷新及进程重启后的恢复；再接模型发现与联网测量。

每批通过独立审查和定向测试后交付，测试账号与生产账号隔离；真实账号凭据和网络配置仅在后台或受控部署配置中提供。

## 凭据导入接口（已部署、待真实验收）

- `POST /api/v1/operator/channel-account-imports`：提交稳定 `import_key`，最多 100 行；每行包括 `row_key`、`platform`、`username`、`password`，可选 `display_alias`、`group_id`。
- `GET /api/v1/operator/channel-account-imports/{import_key}`：读取持久逐行结果，只返回行号、账号引用、状态、脱敏用户名、别名和错误码，不返回原始输入或密文。
- `POST /api/v1/operator/channel-account-imports/{import_key}/rows/{row_key}/retry`：从加密原行显式重试失败项，无需再次提交密码；重复导入不自动重试旧失败行。
- 每行账号、密文和结果原子提交，各行独立成功；同键同内容复用，内容变化冲突。请求中断后先 GET 核对已提交行，不重新生成所有账号。
- CSV 文件／粘贴解析复用 PapaParse（MIT，随 Web 分发许可证）。浏览器仅保存非敏感批次、行标识及完成标识用于恢复；部分结果刷新后重新选择原清单并沿用键续传。密码不进入预览或浏览器持久存储，提交成功后清空明文。
- 导入结果不是实时登录状态。现有逐行登录入口不等于持久队列或已验证自动填表；真实导入、登录和恢复仍需部署后验收。

## 网络版本与执行接缝（版本绑定已部署、出口检查待实现）

代理池地址／认证变更创建不可变修订，不覆盖旧修订；账号区分活动绑定及待生效绑定，绑定包含版本和有效网络快照，现有单账号网络配置可映射为独立绑定，不强迫重新接入账号。登录、模型发现、测量和发布前固定网络版本，恢复、查回及清理必须使用原执行的版本并复核身份及当前授权，不读取“当前代理”猜测历史出口。

更换绑定须等待活动浏览器结束，租约到期不等于浏览器已关闭；旧凭据失效记录连接失败，不切换出口重试。绑定与账号元数据分别更新，避免修改分组时覆盖并发网络变更；缺少历史网络来源时明确无法确认，不回填当前配置。

出口检查仍为待实现契约：复用执行器浏览器网络配置，使用独立无 Cookie 上下文访问受控 HTTPS 探测服务；仅保存脱敏出口标识，不保存响应正文或认证信息。检查只证明当时出口，池成员数及不同地址不等于不同公网出口；库存与版本绑定／原快照恢复已部署，实际恢复仍待验收，自动分配和出口检查仍待实施。
