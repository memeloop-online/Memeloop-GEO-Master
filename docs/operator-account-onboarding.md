# 运营账号接入与出口分配

状态：实施契约；现有账号池支持单账号远程登录、资源组和项目分配，本文新增的批量凭据导入、代理池和供应商接入仍须实施及验收。产品规格书保持不变。

## 操作路径

后台账号池 → 粘贴或上传账号清单 → 检查导入结果 → 逐个登录 → 自动核验并保存连接 → 分配到项目。

- 清单支持平台、用户名、密码、显示别名、资源组及可选代理池。导入界面同时提供逐条添加，避免强制准备文件。
- 导入只建立待登录记录，不把用户名当作平台身份；身份由已登录网站的账户响应确认。
- 登录任务默认按清单顺序进行。遇到扫码或验证码，在现有标准 noVNC 窗口接续，不重复建账号、不要求运营重新录入已保存信息。
- 登录支持凭据表单时通过维护中的浏览器自动化库填写；不新增远程键盘、剪贴板或文本注入协议。未验证网站表单适配时允许在标准远程页面手动登录。
- 后台列出待登录、登录中、已连接、需要重新登录和失败原因。模型菜单、联网测量、发布及会话清理能力各自显示，不由登录状态推导。
- 千问、元宝加入接入范围；实现前核验当前官方网站入口及身份响应。仅能打开页面时不声明账号核验可用。

## 导入与凭据

- 导入请求包含稳定 `import_key`，每行包含稳定 `row_key`；服务端在 operator 作用域保存逐行结果。相同键和内容重试复用结果，同键异内容报冲突，失败行单独重试。
- 接口返回账号引用、行状态和脱敏错误，不返回密码、Cookie、session 或代理口令。列表不显示完整用户名；详情按已有资源管理员权限查看必要账号信息。
- 用户名／密码是接入凭据，已验证浏览器 session 是执行凭据，两者独立加密和版本化。复用现有 operator 作用域密钥管理；不把凭据放入账号 metadata。
- 上传解析内存有界；原文件默认不持久保存，任务只保存必要的加密行数据。预览、错误、审计与日志不得包含明文密码或完整原行。
- 账号分组、停用、凭据轮换和项目分配复用现有服务。项目选择使用 operator 授权的名称目录，取消手填租户／项目 UUID。
- 不修改现有首次初始化命令来绕过其一致性检查；已有部署新增资源管理员需单独的受控身份配置操作。

## 代理池

- 池成员保存协议、地址、端口及加密认证凭据；探测结果只保存连接状态、延迟、最后检查时间和脱敏出口标识。
- 账号绑定固定成员及绑定版本。登录、恢复、模型发现、测量、发布和远端会话清理使用同一版本；不逐请求轮换。
- 支持导入时自动分配不同成员、手动指定成员、查看占用及批量检查。成员数不足或实际出口重复时明确显示，不能声称已获得不同出口。
- 网络地址不同不证明出口 IP 不同。通过运营者配置的探测端点确认实际出口，真实网络配置及结果不进入公开文档。
- 更换绑定在在途任务结束后生效；任务保留原绑定引用供结果查回及清理。代理故障不静默改走默认网络，不通过不断更换 IP 重试已被平台拒绝的操作。
- 代理只负责网络路由与会话稳定性，不保证账号不会受到平台限制。网站验证由账号持有人完成。

## 交付与验收顺序

1. 修复管理员角色映射，已有资源管理员能够进入账号池；普通项目管理员仍不能读取运营池凭据。
2. operator 范围项目目录和选择器，资源组及账号筛选，消除手填内部标识。
3. 加密凭据导入、逐行幂等及登录队列，支持中断后继续和单条重试。
4. 代理池、固定出口分配及真实连接检查；验证代理失效、重复出口、凭据轮换和任务中途更换绑定。
5. 千问、元宝分别验收真实登录、身份保存、刷新及进程重启后的恢复；再接模型发现与联网测量。

每批通过独立审查和定向测试后交付，测试账号与生产账号隔离；真实账号凭据和网络配置仅在后台或受控部署配置中提供。

## 凭据导入接口

- `POST /api/v1/operator/channel-account-imports`：提交 `import_key` 与最多 100 行。每行包含 `row_key`、`platform`、`username`、`password`，可选 `display_alias`、`group_id`。
- `GET /api/v1/operator/channel-account-imports/{import_key}`：读回已持久保存的逐行结果。返回行号、账号引用、导入状态、脱敏用户名、别名和错误码，不返回原始输入或密文。
- `POST /api/v1/operator/channel-account-imports/{import_key}/rows/{row_key}/retry`：从加密原行重试失败项，无需重新提交密码。重复导入本身不重试旧失败行。
- 每行的账号创建、密文和结果在同一事务中提交；不同的行独立成功。重复键且内容相同复用结果，内容改变则冲突；请求中断后以 GET 核对已提交行，不重新生成全部账号。
- 导入状态不是实时登录状态。创建账号后复用现有远程登录及身份保存；自动填表只在对应平台表单适配验证后接入。持久顺序队列及跨进程恢复是后续增量，不以浏览器组件状态代替。

## 网络版本与执行接缝

代理池成员的地址或认证变更创建不可变修订，不覆盖旧修订。账号保存活动绑定与待生效绑定；绑定包含版本和有效网络快照，已有单账号代理配置映射为独立绑定，不强迫重新接入账号。

登录、模型发现、测量、发布启动前统一固定网络版本；后台恢复、发布查回与会话清理从原执行引用取回相同版本，并重新校验账号身份及当前访问权限。不能在清理时直接读取账号“当前代理”来猜测原出口。历史任务缺少网络来源时明确记录无法确认，不回填当前网络。

更换网络等待活动浏览器结束；租约时间经过不代表浏览器已经关闭。旧绑定继续用于已发送任务的核对及清理，旧凭据失效时记录连接失败，不切换出口盲目重试。版本绑定与账号元数据分别更新，避免修改分组时覆盖并发网络变更。

代理检查使用执行器的相同浏览器网络配置，独立无 Cookie 的上下文访问受控 HTTPS 探测服务。检查只证明当时可观测的出口；同地址池成员数量不等于不同公网出口数量。结果保存脱敏出口标识以检测重复，不保存响应正文或认证信息。代理池 CRUD、分配、检查及绑定恢复仍须实现并分别验证。
