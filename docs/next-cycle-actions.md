# 下一周期动作：待实施契约

本文件细化冻结规格的 NextCycleAction，不修改产品范围。**目前未实现**；已有周期推进、正文复用和问题用途投影不能替代下面的执行链。

## 目标与已确认接缝

正式报告 → 有依据的 typed Finding → 持久动作 → 后继周期冻结应用 → 针对优化问题的知识文档 → 原有检查、分发及执行引用。

- `api/reports.rs` 保存报告后单独调度后继；目前只处理初始报告，尚无动作计划。
- `persistence/projects.rs` 创建后继时立即更新当前周期，内容扫描器可以随即启动。动作与后继的绑定必须在首次规划之前完成，不能事后修改封存清单。
- `api/content.rs` 当前简报来自通用文档键，证据取冻结资料的有界片段；尚无问题相关性检索。
- `ContentSemanticDescriptor` 尚无逐项优化目标。修改全局问题簇会使无关文档失效，不能作为逐题优化实现。
- 问题用途投影目前只输出引用，没有生产消费者。新消费者必须冻结报告窗口内的合格观测，不能让较晚尝试改变旧报告动作。
- 当前内容路径的语义生产预留不是货币预算预留；不得把估价零或月预算大于零当作真实费用许可。

## 数据与幂等

分别保存不可变 `NextCycleActionDefinition` 和可变执行记录。定义包含作用域、动作键、原报告/Finding、typed 目标与输入版本、原因码、优化器版本、优先级及明确的估价状态。未知估价保持未知，不填零。

动作键绑定语义原因、目标、相关输入版本和策略，不仅绑定报告或周期 UUID。同键不同定义冲突；报告与动作单独建立关联，允许更正报告关联已有动作而不重新生成或发送。

执行状态区分：

- `scheduled`：已持久排期；
- `applying` / `applied`：正在绑定/已绑定后继周期及文档项；
- `running`：实际业务链已执行；
- `succeeded`：已有该动作要求的真实产物；
- `deferred` / `blocked` / `superseded`：保留原因、重查时间或替代关系。

已绑定清单不等于正文完成；正文通过检查不等于平台发布或公开验证。分别保存并展示实际产物引用，保留全部动作分母。

## 首批动作

`ensure_question_document`：合格优化题的具体缺口生成稳定的 question/market/language FAQ 分支。问题是选题，不是事实依据。生成器只收到该优化题和相关公开知识证据，不收到整份报告、原始测量答案或混合汇总。没有相关来源则明确缺资料。

最小检测可采用版本化的品牌字面未出现规则，并如实标识字面检测，不能宣称语义缺失、事实错误或因果改善。冻结评估、未分类、模拟、缺测、拒答、无搜索证明、错协议及超出窗口的观测不得产生此动作。

`resume_distribution_target`：只恢复可证明尚未发送的原目标，复用原意图和账本。未知、已发送或已验证资产不得以报告动作名义换意图重发；独立查回发现资产也不补造原发送成功。

事实纠错、外部更新/撤回、自动账号登录和资源购买仍需要各自真实能力，不能以保存建议假称执行。独立测量恢复不借道内容优化器处理冻结评估题。

## 原子应用与恢复

1. 正式报告、Finding、封存动作计划及动作行原子保存，零动作也有封存记录；预览零写入。
2. 后继创建与动作计划绑定使用项目事务及唯一后继边界；HTTP、P00 和后台首次内容规划均读取同一绑定。
3. 保留全部基础文档项，只添加或精确改变受影响项；逐项优化目标进入简报及语义指纹。报告/动作/观测 UUID 只用于审计，不进入复用指纹。
4. 持久连接动作、周期、清单项、内容执行、检查版本、分发目标及原意图。扫描覆盖未应用、应用未绑定执行及中断记录，使用游标和 fencing，不依赖内存回调。
5. 更正到来时已开始的周期保持原输入；新增动作进入下一个可冻结周期，不创建兄弟后继、不静默忽略更正。
6. 旧报告和已封存周期不补造历史动作。付费动作接入实际幂等预算预留和用量边界后才能宣称完整自动执行。

## 交互与验收

报告、周期和动作详情提供作用域内分页只读接口。P14 显示原因、费用状态和执行产物；P07 展示到清单项和平台目标的链路；P00 提供受限查询/恢复工具。正常执行不需要审批，客户端不能提交正文、Finding 或成功状态。

必须验证真实原生工作流贯穿动作到 checked revision 和分发 outbox；冻结评估/旧未分类金丝雀隔离；报告保存、后继创建、应用及回写各阶段崩溃恢复；重复事件与更正；不变正文/变体/意图复用；未知发布不重发；来源撤销、暂停、单项缺资料/费用/账号不阻断无关项；PostgreSQL 事务及 UI 权限/窄屏。真实外部发布、搜索、商业对账和容量仍按总规格分别验收。
