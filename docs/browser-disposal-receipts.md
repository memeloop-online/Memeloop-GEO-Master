# 浏览器释放凭证

本接口用于账号顺序登录和固定网络绑定的资源接续，不是远端 AI 对话删除接口。执行器协议与 Rust 客户端已合入主线；后续持久账号占用及业务调用接线见 [`durable-browser-ownership.md`](durable-browser-ownership.md)，网络绑定仍待接入，不能据此宣称代理分配已经生效。

## 内部协议

所有接口复用执行器服务认证，不直接暴露给客户浏览器。

| 请求 | 成功响应与含义 |
|---|---|
| `GET /v1/lifecycle` | `{generation}`，获取本执行器实例的 UUID |
| `POST /v1/sessions`，增加 `expected_generation` | 原启动响应增加 `generation`；必须与请求相同 |
| `POST /v1/sessions/{id}/dispose`，正文 `{expected_generation}` | `{session_id, generation, state: "disposed"}`，该实例已经完成资源释放并拒绝此 ID 再启动 |

实例不符返回冲突，不接触其他实例的资源。无效参数或多余释放字段被拒绝。正在执行任务的会话不能由此接口强行关闭；释放失败保留资源引用以便再次关闭，不能返回成功凭证。

对本实例尚未收到的会话 ID，释放操作先登记禁止再次启动的标记，再确认已释放；后到达的启动请求不能重新创建该 ID。标记也约束旧启动接口，避免重试绕过。启动期间取消继续复用实际资源取得／释放链路，不等待只有关闭浏览器才能结束的身份探测。

## Rust 调用边界

`BrowserBridge` 提供 `lifecycle_generation`、`start_in_generation` 和 `dispose_in_generation`。启动成功必须返回匹配的会话及实例；释放凭证必须同时匹配会话、实例及 `disposed` 状态。普通 404、空成功响应、旧版关闭响应、重定向以及无法解析的响应都不是释放凭证。

调用方须在首次启动之前持久记录实例与会话引用。当前查询到的新实例不能用来推断旧会话归属。启动结果不确定时只尝试同实例释放，不回退到旧 DELETE；即使补偿失败，也保留启动失败供持久协调器对账。

旧 `start`／`close` 协议保持兼容，但不提供持久释放证明。业务调用迁移由持久占用增量完成，部署顺序为执行器先支持新协议，再部署调用方；没有实例信息的历史任务不能以当前实例补造归属证明。

## 后续业务接入

1. 登录、模型发现、测量、发布、查回和清理共用 operator／account 级持久占用。先保存操作、固定网络快照和会话引用，再启动浏览器。
2. 活动与待生效网络绑定分离。旧浏览器确认释放后才提升待生效绑定；超时不是释放证明。
3. 历史任务从原执行引用恢复网络版本，不能读取账号当前代理替代。单账号配置与池绑定复用同一变更事务。
4. API 重启后重新授权打开既有登录桌面，不重新创建账号或会话。执行器实例变化则核对旧运行环境确已终止，不能把任意副本 404 当作旧浏览器不存在。
5. 实际出口检查必须使用同一执行器网络配置；不同代理地址不保证公网出口不同。网络失败不静默直连，不自动换出口重试平台拒绝。

## 容量及证明限制

实例 UUID 与禁止重建标记目前位于执行器内存，标记保留到实例结束，内存随已关闭 ID 数量增长。尚无持久标记压缩或安全回收机制；高吞吐长期运行前须单独验证容量及运行环境轮换。

凭证只证明该执行器实例内的浏览器资源释放，不证明别的副本、已重启的旧进程或供应商服务端会话已经结束。稳定路由、运行环境终止证明和持久协调器属于未完成接入项。远端 AI 对话仍按独立会话生命周期保存原始数据后清理。
